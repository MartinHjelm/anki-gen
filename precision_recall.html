Confusion matrix 5 cards
PromptAnswer
Confusion matrix What is a confusion matrix? A 2×2 table for binary classification that cross-tabulates predictions against ground truth, giving the four outcome counts: true positives, false positives, false negatives, and true negatives.
True positive (TP) What is a true positive (TP)? A positive case that the model correctly predicts as positive.
False positive (FP) What is a false positive (FP)? A negative case that the model incorrectly predicts as positive (a false alarm / Type I error).
False negative (FN) What is a false negative (FN)? A positive case that the model incorrectly predicts as negative (a miss / Type II error).
True negative (TN) What is a true negative (TN)? A negative case that the model correctly predicts as negative.
Precision & recall 6 cards
PromptAnswer
Precision What is precision? The fraction of the model's positive predictions that are actually positive. Precision = TP / (TP + FP). Also called positive predictive value.
Recall What is recall? The fraction of actual positives that the model correctly identifies. Recall = TP / (TP + FN). Also called sensitivity or true positive rate.
In words, what question does precision answer? "When the model says positive, how often is it right?" It measures the quality/trustworthiness of positive predictions.
In words, what question does recall answer? "Of all the real positives, how many did the model catch?" It measures coverage of the positive class.
Which metric — precision or recall — is hurt by false positives, and which by false negatives? False positives lower precision (they sit in its denominator). False negatives lower recall (they sit in its denominator).
Why are precision and recall reported together rather than alone? Each ignores one error type, so either can be gamed in isolation. Predict everything positive → recall = 1 but precision collapses; predict only the single most confident case → precision may be 1 but recall is tiny. Together they cover both false positives and false negatives.
Choosing precision vs. recall 3 cards
PromptAnswer
When should you prioritize recall over precision? When false negatives are more costly than false positives — e.g. disease screening or a smoke detector, where missing a true case is dangerous and extra false alarms are tolerable.
When should you prioritize precision over recall? When false positives are more costly than false negatives — e.g. a criminal conviction or flagging spam, where wrongly acting on a negative case is the expensive error.
Why can precision be 'less meaningful' when actual positives are extremely rare? Precision = TP / (TP + FP). The few real positives cap TP, while the huge negative class generates many false positives in absolute terms even at a low false-positive rate — so FP easily outnumbers TP and drags precision down. The estimate also rests on small positive counts, making it statistically noisy.
Related rates 5 cards
PromptAnswer
Specificity (TNR) What is specificity (true negative rate)? The fraction of actual negatives correctly identified as negative. Specificity = TN / (TN + FP).
False positive rate (FPR / fall-out) What is the false positive rate (fall-out)? The fraction of actual negatives that are incorrectly predicted positive. FPR = FP / (FP + TN) = 1 − specificity.
Accuracy What is accuracy? The proportion of all predictions that are correct. Accuracy = (TP + TN) / (TP + TN + FP + FN).
Why is accuracy misleading on imbalanced data? When one class dominates, a trivial model that always predicts the majority class scores high accuracy. With 1% positives, predicting 'all negative' gives 99% accuracy while catching zero positives.
How are recall, sensitivity, and true positive rate related? They are three names for the same quantity: TP / (TP + FN).
F-measure 3 cards
PromptAnswer
F1 score What is the F1 score? The harmonic mean of precision and recall: F1 = 2 · (precision · recall) / (precision + recall). It is high only when both are high, and is preferred over accuracy on imbalanced data.
Why use the harmonic mean (not the arithmetic mean) for F1? The harmonic mean is dominated by the smaller value, so F1 stays low if either precision or recall is poor. An arithmetic mean would let a high score on one metric mask a terrible score on the other.
The general Fβ score weights recall β times as important as precision: Fβ = (1 + β²) · (P · R) / (β² · P + R). Using F2 emphasizes recall, while F0.5 emphasizes precision.
Thresholds & the tradeoff 5 cards
PromptAnswer
Classification threshold What is a classification threshold? A cutoff applied to a model's raw probability output: scores above the threshold are labeled positive, scores below it negative. The default 0.5 is often not optimal.
What happens to predictions when you RAISE the classification threshold? Fewer examples are called positive, so both true positives and false positives decrease (true negatives rise, false negatives rise). Precision tends to go up; recall tends to go down.
What happens to predictions when you LOWER the classification threshold? More examples are called positive, so both true positives and false positives increase. Recall tends to go up; precision tends to go down.
What is the precision–recall tradeoff? Precision and recall are typically inversely related: tuning the threshold to improve one usually worsens the other, because raising the bar for a positive prediction trades caught positives against false alarms.
Why is the default threshold of 0.5 often a poor choice? It assumes balanced classes and equal misclassification costs. With class imbalance or asymmetric costs, a different threshold gives better precision/recall for the task.
ROC & AUC 7 cards
PromptAnswer
ROC curve What is an ROC curve? A plot of true positive rate (y-axis) against false positive rate (x-axis) as the classification threshold is swept across all values. It visualizes model performance at every threshold.
What do the axes of an ROC curve represent? Y-axis = true positive rate (recall) = TP/(TP+FN); X-axis = false positive rate = FP/(FP+TN).
Where does the ideal classifier sit on an ROC plot, and what is the no-skill line? The ideal point is the top-left corner (0, 1): TPR = 1 with FPR = 0. A no-skill model lies on the diagonal from (0,0) to (1,1).
AUC (area under the ROC curve) What is AUC? The area under the ROC curve — a single number from 0 to 1 summarizing performance across all thresholds, used to compare models.
What does AUC represent probabilistically? The probability that the model ranks a randomly chosen positive example higher than a randomly chosen negative example. It is a measure of ranking/separation quality, independent of any single threshold.
An AUC of 1.0 is a perfect classifier, 0.5 is no better than random (the diagonal), and a value below 0.5 means the model ranks examples wrong more often than chance.
Why is AUC called 'threshold-independent'? It integrates performance over every possible threshold rather than fixing one, so it reflects how well the model separates/ranks the classes regardless of where you set the cutoff.
Imbalance: ROC vs. PR curves 5 cards
PromptAnswer
Precision–recall (PR) curve What is a precision–recall curve? A plot of precision (y-axis) against recall (x-axis) as the threshold varies. Both metrics focus on the positive (minority) class and ignore true negatives.
Where is the ideal point on a PR curve, and what is its no-skill baseline? The ideal point is (1, 1): perfect recall and perfect precision. The no-skill baseline is a horizontal line at precision = the proportion of positive examples in the dataset.
Why can ROC curves look overly optimistic on severely imbalanced data? FPR uses true negatives in its denominator. With a huge negative class, even many false positives barely move the FPR, so the ROC curve and its AUC can look strong while the model performs poorly on the rare positive class.
Why are PR curves preferred for highly imbalanced problems? Precision and recall both concentrate on the minority (positive) class and exclude true negatives, so the PR curve exposes performance on the rare class that an optimistic ROC curve can hide.
How can a model have high ROC AUC yet be nearly useless under severe imbalance? AUC only measures ranking and is built on FPR, which barely moves when the negative class is enormous — so it stays high even when false positives vastly outnumber true positives. At any usable threshold, precision can still be dismal, so the model fails to flag the rare positives despite a strong-looking AUC.
Prediction bias 5 cards
PromptAnswer
Prediction bias What is prediction bias? The difference between the mean of a model's predictions and the mean of the ground-truth labels. Zero prediction bias means the average prediction matches the observed base rate.
How do you calculate prediction bias? Subtract the average ground-truth label from the average predicted value over the data. Example: if 5% of emails are truly spam, a model averaging ~5% predicted spam has near-zero bias.
Name the common causes of prediction bias. Biased or noisy training data (e.g. skewed sampling), over-regularization, bugs in the training pipeline, and an insufficient/inadequate feature set.
How does prediction bias relate to calibration? It is a coarse calibration check: a well-calibrated model has near-zero prediction bias, since its average prediction matches the actual rate. Note that zero bias is necessary but not sufficient — bias can cancel out across subgroups while individual predictions are still wrong.
If a model shows significant prediction bias, what does it signal? Something systematic is off — the model is consistently over- or under-predicting the positive rate — pointing to data, regularization, feature, or pipeline problems rather than mere random error.
Regression metrics 8 cards
PromptAnswer
Mean Absolute Error (MAE) What is Mean Absolute Error (MAE)? The average magnitude of the residuals, ignoring sign: MAE = (1/n) Σ |ŷᵢ − yᵢ|. It is in the same units as the target and treats all errors proportionally.
Root Mean Squared Error (RMSE) What is Root Mean Squared Error (RMSE)? The square root of the mean squared residual: RMSE = √[(1/n) Σ (ŷᵢ − yᵢ)²]. It is in the same units as the target but penalizes large errors more heavily than MAE.
Mean Bias Error (bias) What is bias (mean bias error) in regression? The average signed residual: bias = (1/n) Σ (ŷᵢ − yᵢ). A positive value means the model systematically over-predicts, negative means it under-predicts; near zero means errors cancel on average.
R² (coefficient of determination) What is R² (the coefficient of determination)? The proportion of variance in the target explained by the model: R² = 1 − SS_res / SS_tot, where SS_res = Σ(yᵢ − ŷᵢ)² and SS_tot = Σ(yᵢ − ȳ)². A unitless score that is always ≤ 1 (= 1 only for a perfect fit) and can be negative when the model does worse than predicting the mean.
How do RMSE and MAE differ in how they treat large errors? RMSE squares residuals before averaging, so a few large errors dominate it (outlier-sensitive). MAE weights every error by its absolute size, so it is more robust to outliers. RMSE ≥ MAE always, and the gap grows with error variance.
Why can a model have low MAE/RMSE but still be biased? MAE and RMSE measure error magnitude regardless of direction. Bias (mean signed error) can be near zero even with large magnitudes, or large even when over- and under-predictions partly cancel — so you check bias separately to detect systematic over/under-prediction.
How do you interpret R² values of 1, 0, and negative? R² = 1 means the model perfectly predicts every point; R² = 0 means it does no better than always predicting the mean ȳ; R² < 0 means it does worse than that mean baseline (possible on test data or a badly misspecified model).
Why report bias alongside MAE/RMSE rather than relying on error magnitude alone? Magnitude metrics tell you how far off predictions are, but not in which direction. Bias reveals systematic over- or under-prediction that magnitude metrics hide — two models with identical RMSE can be unbiased or heavily skewed one way.
Bias–variance tradeoff 8 cards
PromptAnswer
Bias (bias–variance sense) What is bias in the bias–variance decomposition? The error from a model's simplifying assumptions: how far its average prediction (over many training sets) is from the true value. High bias means the model is too simple to capture the real pattern — it underfits.
Variance (bias–variance sense) What is variance in the bias–variance decomposition? The error from sensitivity to the particular training set: how much the model's predictions wobble if you retrain on different samples. High variance means the model is too flexible and fits noise — it overfits.
Irreducible error What is irreducible error? The noise floor — error from inherent randomness in the data (and unmeasured factors) that no model can remove, regardless of how good it is.
Bias–variance tradeoff What is the bias–variance tradeoff? Reducing bias (more model complexity) tends to raise variance, and reducing variance (simpler/more regularized model) tends to raise bias. Expected generalization error is minimized by balancing the two, not by minimizing either alone.
Expected test error decomposes into three parts: bias² + variance + irreducible error.
How do bias and variance relate to underfitting and overfitting? High bias → underfitting: the model is too simple, with high error on both training and test data. High variance → overfitting: the model fits the training data (low train error) but generalizes poorly (high test error).
How does model complexity move bias and variance? As complexity increases, bias falls (the model can fit more patterns) but variance rises (it grows more sensitive to the training sample). Total error follows a U-shape — falling, then rising — with a sweet spot in between.
What practical levers shift the bias–variance balance? Toward less variance / more bias: stronger regularization, simpler models, fewer features, more training data. Toward less bias / more variance: more complex models, more features, less regularization. More data mainly reduces variance without adding bias.
